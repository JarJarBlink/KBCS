# ネイティブ関数のバージョン間追跡 v3

## 照合と資料生成

| 以前の実装 | v3の処理 | 小規模の確認 |
| --- | --- | --- |
| 初期matcherの採用を後続の基準に使用 | `interval_alignment.audit` が基準を人手・一意シンボル・一意の命令と構造に限定する。境界不一致、独立した呼出証拠を持つ強い別候補、短い重複コードの弱い採用を保留する | 誤対応を2つの独立呼出関係で保留 |
| 関数の並びと近傍から候補検索 | `tracking_pair.interval_candidates` が最大48件ずつの両区間を、挿入・欠落を許す重み付き列照合で探索する。順序も件数も補助証拠。大きい区間と交差区間は既存の全域候補検索へ進む | 2件挿入、件数相殺、基準の前後逆転 |
| 命令ブロック、CFG、参照から採用 | `instruction_matcher.refine` が候補の命令・CFG・参照と双方向の次点差を評価する。列照合は候補プールを補い、採用スコアは上げない | 重複候補は保留、3版矛盾で辺を隔離 |
| 対応した命令位置のイベントを比較 | `logic.compare` と `effects.changes` が片側の未対応位置、再配置、参照先、値や幅の変化を記録する。比較行は元の命令バイトと実在する逆アセンブリのアンカーを使う | CALLを先頭に1件挿入して残りのCALLは誤報ゼロ、本文・分割先のアンカー |
| 関数ページから比較行へ移動 | `tracking_pages` が公開順で前後の版を決定し、採用済みの相手先と比較行を同じ台帳から作る。`publication_gate` が実ファイル、対応行からの戻り先、両側の一致、出典を検査する | 4版目追加、中間版の追加、同版出典の変更、偽リンク拒否 |

初期採用の監査に使う基準点は先に固定する。厳密な構造照合で増えた基準も、元の独立基準からの支持を必要とする。全域検索は命令片、CFG、参照、呼出関係などを再利用する。候補上限や解析境界で不足した根拠は台帳に残す。中間版との両辺が採用されているかを追跡し、非隣接の直接経路は矛盾の調査に使う。

検査範囲で差が見つからない場合、機械語・再配置差の候補、ロジック差の候補、参照や命令位置の未解決を区別する。呼出の集計差が1件なら、対応しない呼出位置を示す。片側の命令を見つけられない範囲は未完了とする。実行時の同値性、別名参照、複数経路をまたぐ値、間接呼出の解決には限界がある。

## 出典と台帳

- `datasets` と `nodes` が版・ABI・SO SHA・解析リビジョン・絶対アドレス・関数詳細の正規パスを保持する。`matcher.tracking show` の `endpoints` で両側を確認できる。
- `relations` は採用・保留・候補と方式を記録する。`address_delta_hex` は新旧入口の差で、旧入口から新入口への移動を示す。`anchor_audit`、候補台帳、`instruction_alignment`、`logic` に根拠、評価率、曖昧さを保つ。
- `interval_evidence` に境界の両側の入口、順位、関数数と差、両端の移動量、交差、検索範囲と打切りを保存する。`entry_states` の未対応入口は `unmatched` / `needs_review` となり、`confirmed_counterpart` は空になる。経路矛盾は `relations` と `conflict_edges` で調べる。
- `navigation.json` の明細行は採用済みの旧入口、新入口、比較ファイルとアンカーを束ねる。版ごとの `function-comparisons.json` は両側の出典と、採用時だけ付く `match`、比較行の正規パスを持つ。版・ABI・ライブラリ・SO SHA・解析リビジョンを揃えて資料を生成する。
- SQLiteのv3は別設定IDになる。署名は照合・描画・検証コード、ポリシー、入力のキャッシュ・構造、手動判断を含む。既存v2 SQLiteは資料プレビューに使える。v3のActionsはv3の完成DBを要求する。

## 検証範囲

小規模fixtureでは挿入後の順序維持、短い同型候補の保留、アンカー監査、命令位置のリンク、4版の更新、中間版追加後のアーカイブ化、リンク改変の拒否を検査した。既存資料の検証規模は79,986関数ページ、159,972区間リンクだった。v3での全件照合・全件リンク検査・精度・速度・最大メモリ・容量は未測定。既存の匿名サンプルや名前付きホールドアウトから匿名関数全体の精度は推定できない。新規実行はペア単位の時間・ピークメモリを記録し、公開ゲートでも検査件数と実行時間を記録する。
