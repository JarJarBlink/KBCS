# 戦闘の録画

準備画面の「録画」で予約し、戦闘の初期暗転から録画できる。素材の読み込み進捗と取り消しは下部に表示する。結果画面のOK操作で暗転した後、準備に戻る時点で録画を終了する。戦闘中の操作盤からも録画を開始できる。録画バーでは一時停止・再開・終了を操作する。録画バーを隠した場合は「録画」ボタンか Alt+Shift+R で再表示する。

中央だけの録画では、戦闘盤面とHUDのCanvasを描画提出直後に合成する。画面共有の許可は不要で、KBCSの録画操作や読み込み文字は映像に含まれない。画面共有の録画では、利用者が指定したウィンドウ・タブの全体、またはプレビューでドラッグ指定した範囲を撮る。選択枠の内側をドラッグすると移動し、四隅・辺のハンドルでサイズを変える。矢印キーでも枠を移動できる。範囲の表示と保存される切り抜きは同じ動画座標を使う。共有機能の有無や選択できる画面は環境・OSの許可に依存する。

入力元は最大30 FPSで録画用Canvasに渡す。中央では戦闘描画の解像度を使い、画面共有では選択した範囲の解像度を最大3840×2160まで使う。映像ビットレートは画素数に応じて10～40 Mbpsを指定する。録画中の画面比率変更には黒帯で対応する。形式は録画前にWebMまたはMP4から選択し、WebViewがエンコードできる形式だけを有効にする。音声を有効にするとKBCSのBGMとSEをWeb Audioの録画経路へつなぐ。マイクと他のアプリの音声は取得しない。録画データが256 MiBに達すると停止する。

終了時は中央のダイアログを開く。「後で」を選ぶと録画ボタンで再表示でき、「破棄」で動画を破棄する。「動画を保存」は動画を512 KiBずつ専用プロトコルまたはループバック経由でKBCSへ渡す。ホストの確認済みバイト数を進捗に使い、全内容の確定を受けて保存先を表示する。中断時は一時ファイルを破棄し、保存に失敗した録画は同じ画面から再試行できる。録画ファイルを外部へ送信しない。
