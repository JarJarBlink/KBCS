# 戦闘の録画

準備画面の「録画」で予約し、戦闘の初期暗転から録画できる。素材の読み込み進捗と取り消しは下部に表示する。結果画面のOK操作で暗転した後、準備に戻る時点で録画を終了する。戦闘中の操作盤からも録画を開始できる。録画バーで一時停止・再開・終了・保存。録画バーを隠した場合は「録画」ボタンか Alt+Shift+R で再表示する。

中央だけの録画では、戦闘盤面とHUDのCanvasを描画提出直後に合成する。画面共有の許可は不要で、KBCSの録画操作や読み込み文字は映像に含まれない。画面共有の録画では、利用者が指定したウィンドウ・タブの全体、またはプレビューでドラッグ指定した範囲を撮る。左右のサイドバーや下部の詳細を含めるには、共有した画面全体か、必要な部分を含む範囲を指定する。共有機能の有無や選択できる画面は環境・OSの許可に依存する。

入力元は最大30 FPSで録画用Canvasに渡し、出力は最大1280×720に収める。録画中の画面比率変更には黒帯で対応し、エンコーダーの解像度を途中で変更しない。音声を有効にするとKBCSのBGMとSEをWeb Audioの録画経路へつなぐ。マイクと他のアプリの音声は取得しない。MediaRecorderが対応するWebMまたはMP4を使い、サーバーへ送らずブラウザー内で保存する。録画データが256 MiBに達すると停止して保存できる状態にする。次の録画が完了すると保存リンクは新しい動画に切り替わる。

画面共有が使えない場合は中央録画を利用できる。録画が失敗した場合は録画バーに通知し、戦闘の状態や乱数には影響させない。
