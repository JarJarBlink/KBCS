# 戦闘の録画

準備画面の「録画」で予約し、戦闘の初期暗転から録画できる。素材の読み込み進捗と取り消しは下部に表示する。結果画面のOK操作で暗転した後、準備に戻る時点で録画を終了する。戦闘中の操作盤からも録画を開始できる。録画バーでは一時停止・再開・終了を操作する。録画バーを隠した場合は「録画」ボタンか Alt+Shift+R で再表示する。

中央だけの録画では、戦闘盤面とHUDのCanvasを描画提出直後に合成する。画面共有の許可は不要で、KBCSの録画操作や読み込み文字は映像に含まれない。画面共有の録画では、利用者が指定したウィンドウ・タブの全体、またはプレビューでドラッグ指定した範囲を撮る。選択枠の内側をドラッグすると移動し、四隅・辺のハンドルでサイズを変える。矢印キーでも枠を移動できる。範囲の表示と保存される切り抜きは同じ動画座標を使う。共有機能の有無や選択できる画面は環境・OSの許可に依存する。

MP4とWebMは最大30 FPSで録画用Canvasに渡す。中央では戦闘描画の解像度を使い、画面共有では選択範囲を最大3840×2160まで使う。標準の映像ビットレートは10～40 Mbps、高画質は18～100 Mbpsを画素数に応じて指定する。実際の映像ビットレートはWebViewのエンコーダーに依存する。録画中の画面比率変更には黒帯で対応する。WebViewがエンコードできる形式を表示し、音声を有効にするとKBCSのBGMとSEをWeb Audioから録る。MP4とWebMは256 MiBで録画を停止する。

「可逆 PNG連番」は中央の戦闘画面で選べる。`battle-recording.js` が盤面とHUDを描画バッファと同じ寸法で合成し、`battle-recording-frames.js` が提示したフレームごとにPNGを生成する。`recording_frames.rs` がPNGを分割で受け取り、一時ZIPに順番に保存する。ZIPには `frames/` と、フレームごとのマイクロ秒時刻を持つ `timeline.json` が入る。音声は含まない。元の寸法を保つため、画面比率の変更でバッファの寸法が変わると録画を停止する。4フレームの書き込み待ち、108,000枚、またはPNGの合計8 GiBの上限に達すると通知し、それまでに受け付けた分を確定する。書き込みエラーは画面に表示する。

終了時は中央のダイアログを開く。「後で」を選ぶと録画ボタンで再表示でき、「破棄」で動画を破棄する。「動画を保存」は動画を512 KiBずつ専用プロトコルまたはループバック経由でKBCSへ渡す。ホストの確認済みバイト数を進捗に使い、全内容の確定を受けて保存先を表示する。中断時は一時ファイルを破棄し、保存に失敗した録画は同じ画面から再試行できる。PNG連番は録画中からディスクに書き込み、「ZIPを保存」でファイル名を確定する。録画ファイルを外部へ送信しない。
