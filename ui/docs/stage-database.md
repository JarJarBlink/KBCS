# ステージDBの表示

ステージ検索はマップと個別ステージを切り替えられる。上部の検索欄では表示名、`N000(0)`のようなマップID、`N000-0`のようなステージIDを検索できる。左の絞り込みは両方の表示で共通。結果はステージ単位で条件を照合してからマップへ集約するため、複数の異なるステージにまたがるAND一致は発生しない。マップ名の下に一致したステージへのリンクを最大3件表示する。

マップ概要では、各ステージの統率力、難易度、出現する敵と報酬を一覧で比較できる。ステージを選ぶと基本情報、敵の出現、報酬、出撃制限・特殊ルール、背景・BGMの順に表示する。冠とステージの選択はURLで復元する。体力・攻撃力などの列は右サイドバーで追加でき、敵のリンク先には出現行の倍率と冠を渡す。

`search-index.js` → `selectStageRows` / `selectStageMaps` が検索結果を構築する。`stage-detail.js` は検索索引でリンク先を特定し、`/api/stages?map=…` でマップ詳細を取得する。`catalog-view.js` は共通のギミック表示と敵アイコン、`view.js` は出現表と報酬・制限の表示を担当する。敵の能力値、獲得XP、報酬抽選は個別ステージで必要になったときに既存のネイティブ計算を使う。DBスキーマとアセット取り込み仕様は既存のものを使う。

検索と詳細のHTML、`search.js`、`model.js`、`view.js`、`catalog-view.js`、`stage-catalog.css` はKBCS側で保守する。`scripts/sync-ui.py` は共通の依存モジュールとヘッダーを同期する。

マップで敵や報酬を見比べる構成と、個別ステージで出現条件を読む構成を参考にした。 [bc-eventのマップ一覧](https://bc-event.pages.dev/stage/PR000) · [JDBのマップ詳細](https://jarjarblink.github.io/JDB/map.html?cc=ja&id=39000)
